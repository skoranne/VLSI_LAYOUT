\section{Exact Polygon-Level Topologicals (\texttt{TrapTopoModule})}

Physical verification rule decks rely heavily on spatial-relation selectors (\texttt{INTERACT}, \texttt{CUT}, \texttt{TOUCH}, \texttt{INSIDE}, \texttt{OUTSIDE}, \texttt{EQUAL}, \texttt{DISJOINT}, \texttt{MEET}, \texttt{OVERLAPS}, \texttt{COVERS}, \texttt{COVEREDBY}, \texttt{CONTAINS}, and their \texttt{NOT\_*} complements) that select \emph{whole polygons} of layer $A$ based on their DE-9IM topological relation to layer $B$.

\texttt{src/trap\_topo.f90} evaluates all 24 operators exactly without any Boolean snap rounding:
\begin{enumerate}
  \item \textbf{Component Labeling:} Both $A$ and $B$ are labeled via \texttt{TrapPNum}, yielding canonical polygons $P_A$ and $P_B$.
  \item \textbf{Broad-Phase Grid + Narrow-Phase \texttt{trap\_contact}:} A uniform spatial grid (\texttt{PieceGrid}) indexes $B$'s trapezoids. For each trapezoid $a \in A$, nearby trapezoids $b \in B$ are classified by exact \texttt{trap\_contact(a, b)} into interior overlap (\texttt{f\_ov}), 1D segment touch (\texttt{f\_t2}), or 0D point touch (\texttt{f\_t1}).
  \item \textbf{Zero-Rounding Gap-Complement Coverage:} To decide whether polygon $a \subseteq B$ (needed for \texttt{INSIDE}, \texttt{CUT}, \texttt{EQUAL}, \texttt{COVEREDBY}, \texttt{CONTAINS}, \texttt{COVERS}, \texttt{OVERLAPS}) without rounding, \texttt{coverage()} inspects each piece $p \in a$ against the nearby pieces of $B$:
  \begin{quote}
    Between consecutive horizontal rows $y_k < y_{k+1}$ of $B$'s pieces intersecting $p$'s bounding box, $B$'s interior-disjoint pieces are sorted left-to-right by exact $x$. The complement $\mathbb{R}^2 \setminus B$ inside slab $[y_k, y_{k+1}]$ is simply the sequence of \emph{gap trapezoids} between consecutive $B$ pieces, bounded by $B$'s own exact lattice lines!
  \end{quote}
  Piece $p$ is covered by $B$ if and only if no gap trapezoid overlaps $p$ with positive area (\texttt{trap\_overlap\_positive}). Checking whether a gap in slabs one row beyond $p$ meets $p$ along a segment decides whether $\partial p \cap (\mathbb{R}^2 \setminus B)$ has 1D contact (distinguishing \texttt{COVEREDBY} from strict \texttt{INSIDE}).
\end{enumerate}

\section{Polygon-Component Geometric Predicates (\texttt{TrapPredModule})}

\subsection{Key Algorithmic Details and Hardening}

\begin{enumerate}
  \item \textbf{Single C++ Loop Extraction:} \texttt{TrapPredSelect} never invokes both \texttt{TrapPolyOutline} (\texttt{ldb\_trapset\_measure}) and \texttt{ldb\_trapset\_loops}. When loops are extracted (\texttt{need\_loops = .true.}), hole counts (via exact \texttt{i128} signed loop area) and perimeter are computed directly from the loops.
  \item \textbf{Origin-Shifted $O(n_h)$ Rotating Calipers:} \texttt{poly\_hull\_mabr} builds the strictly convex CCW hull via Andrew's monotone chain using exact \texttt{i128\_cmp\_prod}, shifts all hull coordinates by $(o_x, o_y) = (h_x(1), h_y(1))$ to eliminate \texttt{real64} catastrophic cancellation at $10^8\text{ dbu}$, and tracks three monotonic caliper pointers (\texttt{iright}, \texttt{itop}, \texttt{ileft}) to compute both \texttt{DIAMETER} and MABR in $O(n_h)$ time.
  \item \textbf{Exterior \texttt{NOTCH} Excluding Holes:} \texttt{poly\_min\_notch} collects only edges belonging to outer CCW loops (signed area $> 0$, excluding CW hole loops so internal hole widths are never misclassified as exterior notches), sorts segments by $x_{\min}$ for sweep-line early exit, and verifies three conditions on every candidate closest-point segment $(c_1, c_2)$: its midpoint is outside the polygon (\texttt{.not. point\_in\_loops}), strictly off all boundary edges (\texttt{.not. point\_on\_loops\_boundary}), and the open segment crosses no polygon edge (\texttt{.not. open\_seg\_crosses\_loops}).
  \item \textbf{\texttt{ENCLOSE\_RECTANGLE} Slab-Core Intersection:} \texttt{poly\_enclose\_rect} first applies O(1) area, MABR, and diameter pruning, then tests candidate orientations $\theta \in [0, \pi)$ (MABR angle, all polygon edge angles, and a $5^\circ$ uniform grid) in both $(W, H)$ and $(H, W)$ orientations. For each $\theta$, \texttt{rect\_fits\_at\_angle} rotates the origin-shifted polygon by $-\theta$, builds candidate bottom rows $y_0$ (every vertex $r_y$, $r_y - H$, exact slanted-edge balance points $x_{e_1}(y_0) = x_{e_2}(y_0 + H)$ for $n_{\text{pts}} \le 64$, and uniform slices), and intersects the exact horizontal slab cores across $[y_0, y_0 + H]$ using dynamically sized scanline buffers (eliminating any fixed crossing cap on wide comb/mesh polygons).
  \item \textbf{Whitespace CTR Argument Parser:} \texttt{AnyAngleParsePredArgs} in \texttt{src/anyangle\_ops.f90} replaces Fortran list-directed \texttt{read(rest, *)} (which treats \texttt{/} in \texttt{/=} as end-of-record!) with a dedicated whitespace tokenizer supporting \texttt{!=}, \texttt{/=}, compound ranges (\texttt{> 0.1 < 0.5}, \texttt{<= 0.5 >= 0.1}), and two-word \texttt{NOT <PRED>}.
\end{enumerate}

\section{Measured Predicate Consistency on Rotated \texttt{SDT16S}}

Running \texttt{MAGPARSER.exe} on \texttt{SDT16S} at \texttt{R000}, \texttt{R001}, and \texttt{R015} verifies exact rotational invariance and \texttt{NOT\_*} partitioning at scale:
\begin{itemize}
  \item \texttt{poly} (\texttt{66:20}, 485,155 polygons, 4.32M traps at \texttt{R015}): \texttt{AREA > 0.1 < 0.5} selects exactly \textbf{108,431} polygons at \texttt{R000}, \texttt{R001}, and \texttt{R015}; \texttt{NOT\_AREA > 0.1 < 0.5} and \texttt{NOT AREA > 0.1 < 0.5} select exactly \textbf{376,724} ($108{,}431 + 376{,}724 = 485{,}155$).
  \item \texttt{mcon} (\texttt{67:44}, 1,107,034 polygons, 3.32M traps at \texttt{R015}): \texttt{IS\_RECTANGLE\_WITH\_ROTATION} and \texttt{IS\_SQUARE\_WITH\_ROTATION} select all \textbf{1,107,034} rotated square contacts at both \texttt{R000} and \texttt{R015} in $2.31\text{ s}$ total ($0.30\text{ s}$ loop extraction, $0.08\text{ s}$ parallel evaluation); \texttt{NOT\_IS\_SQUARE\_WITH\_ROTATION} selects \textbf{0}.
\end{itemize}

\section{Control-File (\texttt{.ctr}) Usage Reference}

Listing~\ref{lst:ctr_example} illustrates a complete \texttt{MAGPARSER} control file exercising every any-angle capability---Booleans, morphology, polygon topologicals, positive and \texttt{NOT\_*} predicates with compound ranges and \texttt{/=}, FASCL properties, and connectivity---on a rotated OASIS layout.

\begin{lstlisting}[style=ctrstyle,caption={Complete \texttt{MAGPARSER} any-angle \texttt{.ctr} script demonstrating Booleans, morphology, topologicals, predicates, and FASCL.},label={lst:ctr_example}]
program ANYANGLE_DEMO
var temp_folder /tmp/opencode/demo/
var temporary_layers 2
var anyangle 1
decl design d1 = /scratch1/skoranne/OSS_EDA_TOOLS/DESIGNS/ROTATION/SDT16S_R015.oas
decl memory t1 = nothing
exec init t1:nothing

# 1. Two-layer Booleans (single shared snap rounding)
exec run t1:gate     = d1:66:20 * d1:65:20
exec run t1:diff_not = d1:65:20 ! d1:66:20
exec run t1:poly_xor = d1:66:20 ^ d1:65:20

# 2. Morphology (Minkowski collar duality)
exec run t1:poly_grow   = d1:66:20 GROW nothing 0.02
exec run t1:poly_shrink = d1:66:20 SHRINK nothing 0.01

# 3. Polygon-level DE-9IM Topologicals (+ NOT_*)
exec run t1:poly_int   = d1:66:20 INTERACT d1:65:20
exec run t1:poly_cut   = d1:66:20 CUT d1:65:20
exec run t1:poly_disj  = d1:66:20 NOT_INTERACT d1:65:20

# 4. Polygon-component Predicates (+ NOT_*, /=, compound ranges)
exec run t1:mid_area   = d1:66:20 AREA nothing > 0.1 < 0.5
exec run t1:out_area   = d1:66:20 NOT_AREA nothing > 0.1 < 0.5
exec run t1:non_quad   = d1:66:20 VERTEX nothing /= 4
exec run t1:rot_sq     = d1:67:44 IS_SQUARE_WITH_ROTATION nothing
exec run t1:not_sq     = d1:67:44 NOT IS_SQUARE_WITH_ROTATION nothing
exec run t1:fit_rect   = d1:66:20 ENCLOSE_RECTANGLE nothing 0.14 0.5
exec run t1:small_ntch = d1:66:20 NOTCH nothing < 0.2

# 5. FASCL per-polygon properties & CONNECT
PROPERTY:A = d1:66:20 FASCL [ (id) AREA(id) ] d1:nothing
CONNECT STACK SKY130 d1
PROPERTY:N = d1:68:20 FASCL [ (id) NET_ID(id) ] d1:nothing
exec measure t1:gate t1:mid_area t1:rot_sq
\end{lstlisting}

\begin{lstlisting}[caption={Whitespace-tokenized predicate argument parser (\texttt{AnyAngleParsePredArgs}) in \texttt{src/anyangle\_ops.f90} avoiding Fortran's \texttt{/} list-directed delimiter trap.},label={lst:arg_parser}]
subroutine next_ws_tok(s, pos, tok)
  character(len=*), intent(in) :: s
  integer, intent(inout) :: pos
  character(len=*), intent(out) :: tok
  integer :: n, i0
  tok = ''; n = len_trim(s)
  do while (pos <= n)
     if (s(pos:pos) /= ' ' .and. s(pos:pos) /= char(9)) exit
     pos = pos + 1
  end do
  if (pos > n) return
  i0 = pos
  do while (pos <= n)
     if (s(pos:pos) == ' ' .or. s(pos:pos) == char(9)) exit
     pos = pos + 1
  end do
  tok = s(i0:pos - 1)
end subroutine next_ws_tok
\end{lstlisting}
